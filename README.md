# Справа проти Липучки

Міні-гра для уроку 3 «Суд щоденних справ» (модуль «Сміливий голос», Зала 3 «Коли тиснуть»), LetMe/teens. Замінює гру «Чат з Липучкою».

Діти — слідчі суду. Вони впізнають прийоми тиску в доказах і відповідають Липучці «щитом». 7 доказів ≈ 8 хвилин.

- **Екран гри:** `index.html`. Його тренер демонструє дітям.
- **Пульт-майстер:** `pult.html`. Відкривається в сусідній вкладці, на другому моніторі або на телефоні. Його не демонструють.

## Як провести
1. Відкрийте `index.html`. Клацніть у кутку «🔗 Пульт» → «Відкрити пульт у новій вкладці». Зелена крапка означає, що пульт підключено.
2. У Zoom / Meet демонструйте лише вкладку з екраном гри. Клавіша `F` вмикає повний екран.
3. Далі йдіть за пультом. На кожному кроці там є одне речення «що робимо», текст для читання вголос і одна-дві кнопки.

Клавіші на екрані гри, якщо пульт не працює:
- `F` — повний екран;
- `Пробіл` — далі;
- `1`–`6` — обрати прийом;
- `Esc` — на початок.

## Файли
- `data.js` — прийоми, докази й тексти.
- `game.js` — логіка екрана гри, джерело стану.
- `pult.js` — логіка пульта.
- `sync.js` — синхронізація: BroadcastChannel `sprava-lypuchky`, за потреби ще й Firebase.
- `config.js` — налаштування Firebase.

Стан зберігається в `localStorage` браузера, де відкрито екран гри, тож перезавантаження будь-якої вкладки нічого не ламає. Кнопка «↩ Назад» у пульті скасовує останній крок.

## Пульт на телефоні (необов'язково)
1. Створіть Firebase Realtime Database і впишіть її адресу в `config.js` → `databaseURL`.
2. Задайте правила бази:
```json
{
  "rules": {
    "rooms": {
      ".indexOn": ["expires"],
      ".read": "query.orderByChild == 'expires' && query.limitToFirst <= 50",
      "$code": {
        ".read": "$code.matches(/^[0-9]{4}$/)",
        ".write": "$code.matches(/^[0-9]{4}$/)"
      }
    }
  }
}
```
3. На екрані гри клацніть «🔗 Пульт»: з'являться код кімнати і посилання. На телефоні відкрийте `pult.html?room=КОД` або введіть код у меню ⚙️ пульта.

Кімнати старші за 12 годин екран видаляє під час запуску.

Безпека: усі докази — тиск від знайомого однолітка. Незнайомців і небезпечних ситуацій у грі немає; тему «червоної печатки» розглядають на уроці окремо.
