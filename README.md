# Чат з Липучкою

Міні-гра для уроку 3 «Суд щоденних справ» (модуль «Сміливий голос», Зала 3 «Коли тиснуть»), LetMe/teens.

- **Екран гри:** `index.html`. Його тренер демонструє дітям.
- **Пульт тренера:** `pult.html`. Відкривається в сусідній вкладці, на другому моніторі або на телефоні. Його не демонструють.

## Як провести
1. Відкрийте `index.html`, потім натисніть у кутку «🔗 Пульт», щоб відкрити пульт у сусідній вкладці (або відкрийте `pult.html` вручну). Зелена крапка означає, що пульт підключено.
2. У Zoom / Meet демонструйте лише вкладку з екраном гри. Клавіша `F` вмикає повний екран.
3. У пульті:
   - оберіть чат;
   - натисніть «▶️ Липучка пише»;
   - впишіть відповідь дитини або клацніть готову фразу;
   - оцініть відповідь: 🟢 / 🔵 / 🟡 / 🔴.

Клавіші на екрані гри, якщо пульт не працює:
- `F` — повний екран;
- `Esc` — до списку чатів;
- `1`–`5` — обрати чат у списку;
- `1` / `2` / `3` / `4` — оцінка 🟢 / 🔵 / 🟡 / 🔴 (без тексту з'являється «🎙️ Відповідь голосом»);
- `Пробіл` — пропустити «друкує…», запустити раунд або перемотати після стоп-кадру.

## Файли
- `scenarios.js` — сценарії та шпаргалка.
- `game.js` — логіка екрана гри, джерело стану.
- `pult.js` — логіка пульта.
- `sync.js` — синхронізація: BroadcastChannel `lypuchka-chat`, за потреби ще й Firebase.
- `config.js` — налаштування Firebase.

Стан зберігається в `localStorage` браузера, де відкрито екран гри, тож перезавантаження будь-якої вкладки нічого не ламає.

## Пульт на телефоні (необов'язково)
1. Створіть Firebase Realtime Database і впишіть її адресу в `config.js` → `databaseURL`.
2. Задайте правила бази:
```json
{
  "rules": {
    "rooms": {
      ".indexOn": ["expires"],
      ".read": "query.orderByChild == 'expires' && query.limitToFirst <= 50",
      "$code": {
        ".read": "$code.matches(/^[0-9]{4}$/)",
        ".write": "$code.matches(/^[0-9]{4}$/)"
      }
    }
  }
}
```
3. На екрані гри клацніть «🔗 Пульт»: з'являться код кімнати з 4 цифр і посилання. На телефоні відкрийте `pult.html?room=КОД` або введіть код у пульті.

Кімнати старші за 12 годин екран видаляє під час запуску.

Безпека: сценаріїв із незнайомцями немає. Липучка — завжди знайомий однокласник.
